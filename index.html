TFT Replay Viewer · 战斗日志回放

导入战斗日志，核对位置、状态与伤害事件。文件只在当前浏览器处理，不上传。

也可拖入 JSON / JSON.gz；最多 20 场，单文件 50 MB，解压后 100 MB。支持完整 AlphaSim 单场响应及 request / response 包装记录。

这是日志查看器，不是真实游戏录像。采样间隔以导入的时间轴为准；事件给出了结算数值，但没有完整返回伤害公式、暴击判定和减伤计算链。因此这里能核对“输入与输出”，不能证明模拟器与游戏一致。
